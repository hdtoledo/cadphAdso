Fases del Proyecto Formativo ADSO

Estructura metodológica del programa en el Centro Agroempresarial y Desarrollo Pecuario del Huila.

1

Fase de Análisis

448h Cargadas
  • Identificar las necesidades del cliente y del sector productivo de Garzón.
  • Elaborar el mapa de procesos de la organización.
  • Definir los requerimientos funcionales y no funcionales (IEEE 830).
  • Modelar historias de usuario y diagramas de casos de uso UML.
3 Actividades · 14 Sesiones
2

Fase de Planeación

576h Planificadas
  • Diseñar la arquitectura tecnológica de la solución de software.
  • Construir el modelo relacional de base de datos normalizado.
  • Diseñar las interfaces de usuario (UI) y la experiencia de usuario (UX).
  • Planificar el cronograma del proyecto bajo metodología ágil (Scrum).
Modelado MER/MR & Figma
3

Fase de Ejecución

672h Planificadas
  • Codificar los módulos del sistema según los estándares de codificación.
  • Integrar la persistencia de datos mediante ORM o consultas optimizadas.
  • Implementar seguridad, control de acceso y validación de entradas.
  • Gestionar el código colaborativo en GitHub mediante ramas y pull requests.
Full-Stack & APIs RESTful
4

Fase de Evaluación

384h Planificadas
  • Ejecutar pruebas funcionales, de seguridad y de rendimiento.
  • Elaborar manuales técnicos de instalación y manuales de usuario.
  • Desplegar la solución en servidores de producción o GitHub Pages.
  • Capacitar al usuario final y realizar la entrega formal del software.
QA & Despliegue en Producción
