# 📝 Fase 1: Análisis — Guías de Aprendizaje

Esta carpeta contiene las Guías de Aprendizaje correspondientes a la **Fase 1 (Análisis)** del proyecto formativo ADSO.

---

## 🎯 Competencias y Temas de la Fase
- **Competencia:** Establecer los requisitos de la solución de software de acuerdo con estándares y procedimiento técnico.
- **Temas:**
  - Levantamiento y recolección de requisitos (técnicas de entrevistas, encuestas, observación).
  - Especificación de Requisitos de Software (**SRS** bajo norma IEEE 830).
  - Casos de Uso y diagramas de actividad UML.
  - Historias de Usuario con criterios de aceptación (formato INVEST).
  - Metodologías de desarrollo de software (Scrum, cascada, Kanban).
