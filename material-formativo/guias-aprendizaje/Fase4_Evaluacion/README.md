# 🛡️ Fase 4: Evaluación — Guías de Aprendizaje

Esta carpeta contiene las Guías de Aprendizaje correspondientes a la **Fase 4 (Evaluación)** del proyecto formativo ADSO.

---

## 🎯 Competencias y Temas de la Fase
- **Competencias:**
  - Verificar los entregables de desarrollo de software contra criterios de calidad y especificaciones.
  - Desplegar la solución de software en el entorno de producción.
  - Elaborar manuales técnicos y de usuario.
- **Temas:**
  - Plan de pruebas de software, diseño de casos de prueba y matrices de verificación.
  - Pruebas unitarias, de integración y funcionales.
  - Despliegue en la nube y servidores (GitHub Pages, Vercel, Netlify, Docker, servidores cloud).
  - Documentación técnica: Manual de Instalación, Manual del Desarrollador y Manual de Usuario.
  - Sustentación final del proyecto formativo y entrega al sector productivo.
