# 📋 Instrumentos de Evaluación — ADSO CADPH

Esta carpeta está destinada a las **Listas de Chequeo**, **Rúbricas** y **Criterios de Evaluación** oficiales utilizados por los instructores para calificar las evidencias de aprendizaje de cada fase.

---

## 🎯 ¿Para qué sirve esta carpeta a la IA?
Cuando un aprendiz o instructor solicite validar si un código, diagrama o entregable cumple con los estándares del SENA, la IA debe cotejar el trabajo contra los instrumentos de evaluación depositados aquí.
