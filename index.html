Explicaciones de los Temas ADSO

Guías técnicas, síntesis de conceptos y ejemplos preparados para los aprendices del SENA Garzón.

1. Maquetación Web Moderna: HTML5 Semántico & Tailwind CSS

Estructura accesible, diseño responsivo móvil-primero (Mobile-First) y utility classes.

Frontend

Conceptos clave: Etiquetas semánticas (<header>, <nav>, <main>, <section>), Grid y Flexbox responsivo, configuración de paletas institucionales y diseño adaptativo a smartphones, tablets y pantallas de escritorio.

Buenas prácticas: No usar estilos inline, garantizar ratios de contraste accesibles (WCAG) y mantener etiquetas descriptivas con IDs únicos.

2. Control de Versiones con Git y Despliegue en GitHub Pages

Manejo de repositorios locales y remotos, ramas, commits semánticos y hosting gratuito.

DevOps / Git

Flujo esencial de trabajo:

git init
git add .
git commit -m "feat: interfaz inicial institucional ADSO CADPH"
git branch -M main
git remote add origin https://github.com/hdtoledo/cadphAdso.git
git push -u origin main

Despliegue GitHub Pages: Activar desde Settings > Pages > Branch: main > Save. El sitio queda activo en https://hdtoledo.github.io/cadphAdso/.

3. Diseño y Gestión de Bases de Datos Relacionales (SQL)

Modelos Entidad-Relación, normalización (1FN, 2FN, 3FN), claves primarias/foráneas y sentencias DDL/DML.

Datos

Competencias SENA: Construcción de tablas con integridad referencial, vistas, disparadores (triggers), procedimientos almacenados y optimización de índices para consultas de alto rendimiento en software empresarial.

4. Lógica de Programación y Construcción de APIs RESTful

Estructuras de datos, POO (Programación Orientada a Objetos), arquitectura de servicios web y seguridad.

Backend

Estándares aplicados: Verbos HTTP estándar (GET, POST, PUT, DELETE), códigos de estado (200, 201, 400, 404, 500), autenticación JWT y manejo defensivo de excepciones.

Fases del Proyecto Formativo ADSO

Estructura metodológica del programa en el Centro Agroempresarial y Desarrollo Pecuario del Huila.

1

Fase de Análisis

  • Identificar las necesidades del cliente y del sector productivo de Garzón.
  • Elaborar el mapa de procesos de la organización.
  • Definir los requerimientos funcionales y no funcionales (IEEE 830).
  • Modelar historias de usuario y diagramas de casos de uso UML.
2

Fase de Planeación

  • Diseñar la arquitectura tecnológica de la solución de software.
  • Construir el modelo relacional de base de datos normalizado.
  • Diseñar las interfaces de usuario (UI) y la experiencia de usuario (UX).
  • Planificar el cronograma del proyecto bajo metodología ágil (Scrum).
3

Fase de Ejecución

  • Codificar los módulos del sistema según los estándares de codificación.
  • Integrar la persistencia de datos mediante ORM o consultas optimizadas.
  • Implementar seguridad, control de acceso y validación de entradas.
  • Gestionar el código colaborativo en GitHub mediante ramas y pull requests.
4

Fase de Evaluación

  • Ejecutar pruebas funcionales, de seguridad y de rendimiento.
  • Elaborar manuales técnicos de instalación y manuales de usuario.
  • Desplegar la solución en servidores de producción o GitHub Pages.
  • Capacitar al usuario final y realizar la entrega formal del software.

Repositorio Oficial & Despliegue en GitHub Pages

Instrucciones para sincronizar, clonar y desplegar este portal en la web.

Repositorio GitHub https://github.com/hdtoledo/cadphAdso.git
URL GitHub Pages https://hdtoledo.github.io/cadphAdso/
Página de Error Personalizada 404.html (Configurada)

Comandos para subir el proyecto a GitHub:

# 1. Verificar estado local

git status

# 2. Agregar archivos creados

git add .

# 3. Crear commit

git commit -m "feat: interfaz institucional SENA CADPH Garzon con Tailwind CSS y GitHub Pages"

# 4. Asegurar rama principal main

git branch -M main

# 5. Conectar con el repositorio remoto

git remote add origin https://github.com/hdtoledo/cadphAdso.git

# 6. Subir cambios

git push -u origin main

🚀 Pasos para habilitar GitHub Pages en el repositorio:

  1. Ingresa al repositorio en GitHub: github.com/hdtoledo/cadphAdso.
  2. Ve a la pestaña Settings (Configuración) > menú lateral Pages.
  3. En Build and deployment > Source, selecciona Deploy from a branch.
  4. En Branch, selecciona la rama main y la carpeta / (root).
  5. Haz clic en Save. ¡En un par de minutos tu sitio estará en línea!

¿Dónde se encuentra ubicado el CADPH?

El Centro Agroempresarial y Desarrollo Pecuario del Huila está localizado en Garzón, Huila, liderando procesos de formación técnica y tecnológica.

¿Qué tecnologías se estudian en ADSO?

HTML5, CSS3, Tailwind CSS, JavaScript, TypeScript, Python, Java, SQL, Git/GitHub, Docker, y metodologías ágiles Scrum.

¿Cómo descargar el diseño curricular?
