# 📐 Fase 2: Planeación — Guías de Aprendizaje

Esta carpeta contiene las Guías de Aprendizaje correspondientes a la **Fase 2 (Planeación)** del proyecto formativo ADSO.

---

## 🎯 Competencias y Temas de la Fase
- **Competencias:**
  - Diseñar la estructura de datos según los requisitos del cliente.
  - Modelar las funciones del software de acuerdo con el informe de requisitos.
- **Temas:**
  - Modelo Entidad-Relación (**MER**) y Modelo Relacional (**MR**).
  - Normalización de bases de datos relacionales (1FN, 2FN, 3FN).
  - Diagramas de Clases, Secuencia y Paquetes UML.
  - Arquitectura de software (Monolítica, MVC, Microservicios, Limpia/Hexagonal).
  - Diseño de interfaces y experiencia de usuario (**UI/UX**) en Figma (wireframes y prototipos interactivos).
