# 💻 Fase 3: Ejecución — Guías de Aprendizaje

Esta carpeta contiene las Guías de Aprendizaje correspondientes a la **Fase 3 (Ejecución)** del proyecto formativo ADSO.

---

## 🎯 Competencias y Temas de la Fase
- **Competencias:**
  - Desarrollar la solución de software de acuerdo con el diseño y metodologías de desarrollo.
  - Implementar la base de datos de acuerdo con los requerimientos del software.
  - Integrar componentes de software siguiendo especificaciones técnicas.
- **Temas:**
  - Maquetación frontend con HTML5 semántico, Tailwind CSS y JavaScript interactivo.
  - Programación orientada a objetos y algoritmos (Java, Python, TypeScript / JavaScript).
  - Desarrollo de APIs RESTful y servicios web.
  - Persistencia y manipulación de datos con SQL (DDL, DML, consultas complejas, triggers) y NoSQL (MongoDB).
  - Control de versiones avanzado con Git y flujos de trabajo colaborativos en GitHub.
